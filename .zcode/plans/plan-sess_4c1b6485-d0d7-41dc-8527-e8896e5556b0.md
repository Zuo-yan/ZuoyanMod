# ZuoyanMod 经验升级系统 + 终极天赋 实施计划

## 调研结论(方案依据)

项目为 **NeoForge 26.3 / MC 1.26.3 / Java 25**,mod id `zuoyanmod`,包根 `org.gwfx.zuoyanmod`。已有可直接复用的组件:

- **玩家数据持久化**:`FourDimensionalSpace.java:96-117` 的 AttachmentType 模式(`copyOnDeath` + `IAttachmentSerializer`,死亡不掉)
- **属性加成**:`RingEventHandler.java:89-97` 的固定 ID transient AttributeModifier 模式
- **原始黑洞已存在**:`entity/PrimordialBlackHoleEntity.java` 有静态 `spawn(ServerLevel, Player, Vec3)`,**已内置对施术者的排除**(L397/L470)——黑洞天赋一行调用即可
- **分子离解效果已存在**:`effect/MolecularDissolutionEffect.java`(每秒 4 点真伤,无视护甲),直接施加即可
- **网络包/按键/纯 Screen**:`PacketHandler`、`RealmKeybindHandler`(共享按键分类)、`DeathNoteScreen`(无 Menu)模式全部现成
- **Y / U 键未被占用**,无 HUD 代码(需新写)

## 一、基础属性升级(5 条 × 10 级,消耗经验等级)

| 属性 | 每级效果 | 实现方式 |
|---|---|---|
| 生命上限 | +2 HP/级(满 +20,10 颗心) | `Attributes.MAX_HEALTH` ADD_VALUE |
| 攻击力 | +0.5/级(满 +5) | `Attributes.ATTACK_DAMAGE` ADD_VALUE |
| 移动速度 | +2%/级(满 +20%) | `Attributes.MOVEMENT_SPEED` MULTIPLY_TOTAL |
| 护甲值 | +2/级(满 +20) | `Attributes.ARMOR` ADD_VALUE |
| 伤害减免 | +2%/级(满 20%) | 伤害事件里乘法减免(护甲结算后) |

- **花费**:升第 n+1 级花 `3+2n` 级经验(3,5,7…21),每条 120 级、全满 600 级;base/step 进 Config 可调
- **数据**:`upgrade/UpgradeData.java` — AttachmentType(`copyOnDeath`),存 5 条等级、已选天赋、各天赋冷却截止 gameTime
- **属性应用**:`upgrade/UpgradeServerHandler.java` — 登录/重生/升级时按 `RingEventHandler` 模式重算 modifier(每条固定 ID);伤害减免挂在项目现有伤害事件处

## 二、终极天赋(5 条全满后选 1 个,Y 键触发)

`upgrade/UltimateTalent.java` 枚举,选择**永久不可更改**:

1. **绝对零度·抓取**(冷却 45s):服务端射线拾取 ≤24 格准星实体 → 逐 tick 拉向自身 → 到达后冰冻 5 秒(缓慢 X 级 + 锁跳跃 + `setTicksFrozen` 冰霜视觉 + 雪花粒子),单目标冻结由服务器 tick 管理
2. **天罚·击飞**(冷却 60s):8 格内所有生物升空(初速 ~1.6 + 水平散布),自然摔落伤害 + 虚弱 III 2 分钟(2400 tick)
3. **分子离解·灌能**(冷却 90s):强化自身,30 秒内下一次近战命中给目标施加**现有** `molecular_dissolution` 效果 3 分钟(4 真伤/秒)
4. **原始黑洞**(冷却 120s):`PrimordialBlackHoleEntity.spawn(level, player, player.position())`,以自身为中心;已有黑洞在场时提示拒绝

触发流程:Y 键 → C2S `TriggerUltimatePacket` → 服务端校验(已选天赋/冷却/条件)→ 执行并落冷却 → actionbar 反馈。

## 三、网络与按键(全部沿用项目现成模式)

- **C2S**:`UpgradeStatPacket(属性下标)`、`ChooseTalentPacket(天赋下标)`、`TriggerUltimatePacket()`、`RequestUpgradeSyncPacket()`(开界面时请求)
- **S2C**:`UpgradeSyncPacket(等级数组/已选天赋/冷却)` → 客户端缓存 `client/ClientUpgradeData`,界面与 HUD 从缓存读
- **按键**(加入现有 `RealmKeybindHandler.CATEGORY` 分类):`key.zuoyanmod.open_upgrade` 默认 **U** 开界面;`key.zuoyanmod.ultimate` 默认 **Y** 触发;在 `client/UpgradeKeyHandler` 的 ClientTickEvent.Post 里消费

## 四、UI(纯代码绘制,无新纹理)

`client/UpgradeScreen.java`(纯 Screen,仿 DeathNoteScreen,GuiGraphics 代码绘制,深色半透明面板 + 金/青描边,配色对齐 klein 主题):

- **顶栏**:当前经验等级、总进度(x/50 级)
- **左栏**:5 条属性行——名称、10 段进度格、当前值→下级值、花费;可负担时高亮,点击升级
- **右栏**:终极天赋 2×2 卡片——未满级灰锁;点击卡片 → 底部展示详述 + 「确认选择」按钮;已选卡片高亮 + 冷却倒计时 + Y 键提示
- **HUD**(`client/UpgradeHudOverlay`,`RenderGuiEvent.Post`):已选天赋后,物品栏上方显示天赋标记 + 冷却剩余秒数,就绪时高亮提示 Y
