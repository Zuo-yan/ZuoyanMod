# 虚空共振泵 · 设计文档（GDD）

状态：**已实现（第一版）** · 2026-09-22
环境：NeoForge 26.3.0.3-beta / Minecraft 1.26.3 · modid `zuoyanmod`

**范围变更（按用户决策）**：
- 明确不做液态暗物质联动：泵只产出暗物质粒子 → 合成暗物质（9:1，3×3 有序合成，JEI 自动识别）。
- 不要求外岛门槛：只判"末地维度 + 正下方为空气"。
- **GUI 已重做为自绘极简布局**（176x146，单进单出）：顶部标题 + 右侧状态；中部「输入槽 — 产出进度条 — 输出槽」一行；下方一条 5 段刻度共振储备条；下半为玩家背包。不再套用原版熔炉纹理（熔炉那套燃料槽 + 大箭头对"只进只出"的机器是多余装饰）。
- **方块改为四面各不相同**：正面（观察窗 + 内部共振发光条 + 状态指示灯）/ 顶面（圆形进气格栅）/ 侧面（散热鳍片）/ 底面（向虚空的共振喷口），并带水平朝向 `FACING`（放置时正面朝玩家）。
- 26.3 API 备忘：GUI 走 `GuiGraphicsExtractor` + `RenderPipelines`；BlockEntity 存档用 `ValueOutput/ValueInput`；`BlockEntityType` 直接构造（无 Builder）；屏幕注册用 NeoForge `RegisterMenuScreensEvent`；方块掉落用 `affectNeighborsAfterRemoval`。
- 贴图与 GUI 均由 `tools/gen_void_pump_textures.py` 程序化生成（纯标准库手写 PNG），坐标常量在脚本与 `VoidResonancePumpScreen` 中成对出现，改一处必须同步另一处。

## 1. Fun Hypothesis

> 这台机器好玩的核心是：**把末地过剩到无处可花的末影珍珠，换成只有"把机器悬在末地虚空边缘"才拿得到的暗物质。**

它卖的不是自动化效率，是地点即价值。玩家为了让它转起来，必须去末地边缘搭平台、把机器架在虚空上方——风险与选址本身就是玩法。

## 2. Design Pillars

| # | 支柱 | 过审用法 |
|---|---|---|
| P1 | 地点即机制 | 维度 + 悬空是硬门槛，不是装饰。放错地方必须老实休眠，且玩家一眼能自查原因 |
| P2 | 过剩变稀缺 | 输入必须是玩家真会过剩的东西；产出必须是稀缺且有用的 |
| P3 | 一眼看懂状态 | 机器常被多人共享，运行状态靠方块外观/粒子表达，不埋在 GUI 里 |
| P4 | 照料有回报 | 守着喂比扔进去就走更高效，效率差就是 skill expression |

## 3. 机制规格

| 项 | 规格 |
|---|---|
| Purpose | 末地过剩物 → 暗物质的唯一合法转化途径 |
| 玩家体验目标 | "我把机器悬在虚空上，喂它，它越喂越快" |
| Inputs | 末影珍珠、龙息、紫颂果（均为末地易过剩物） |
| Outputs | 暗物质粒子 → 合成暗物质（固体）→ 终局合成材料 / 液化成液态暗物质桶 |
| 运行条件 | `level.dimension() == Level.END` **且** 方块正下方为空气 |
| 休眠条件 | 非末地维度 / 下方非空气 / 共振值为 0 / 输出槽满 |
| Failure States | 见 §7 边界情况 |

**不作为燃料的物品（有理由）**：紫颂花（烧掉种子会破坏种植链）、潜影壳（稀缺且另有用途）、末影之眼（通关道具，不该被消耗）。

## 4. 共振机制（燃料 → 速率）

消耗固定为 **1 共振值/tick**，等级由当前共振值决定。等级越高产出越快、但消耗速率不变——所以"堆着喂"天然更划算，激励成立（P4）。

| 共振等级 | 共振值区间 | 产出速率 | 每珍珠折算产出 |
|---|---|---|---|
| L0 | 0 | 休眠 | — |
| L1 | 1–240 | 6.0 秒 / 粒子 | 1.0 |
| L2 | 241–480 | 4.0 秒 / 粒子 | 2.0 |
| L3 | 481–720 | 2.5 秒 / 粒子 | 3.0 |
| L4 | 721–960 | 1.5 秒 / 粒子 | 4.0 |
| L5 | 961–1200（槽上限） | 1.0 秒 / 粒子 | 6.0 |

**燃料价值**

| 燃料 | 共振值 | rationale |
|---|---|---|
| 末影珍珠 | 120 | 直觉锚点：1 珍珠 = 1 粒子（L1 下 6 秒正好产出 1 个），玩家能自己算账 |
| 龙息 | 80 | 末地独有、打龙后通常过剩，价值略低于珍珠 |
| 紫颂果 | 40 | 可自动化种植，供给量大，单价值压到珍珠的 1/3 |

**数值状态**：以上全部 **[PLACEHOLDER · 待 playtest]**。L5 相对 L1 的 6 倍效率是我拍的上限；若测出泛滥，优先把 L5 压到 3 倍（改速率表即可，是独立 tuning lever）。

**投料节奏限制**：单次投料 20 tick（1 秒）冷却，防止瞬间塞满槽位跳过照料环节。槽上限 1200 = 10 颗珍珠。

**粒子→暗物质比值修订为 9:1**（原设计 16:1）：26.3 的 shapeless 配方 ingredient 数量上限是 9（`List is too short: 0, expected range [1-9]`），改走 3×3 有序合成。比值变小意味着暗物质产出提高约 78%，若 playtest 出现 B 类信号（泛滥），优先调高粒子需求量——但受限于 9 格，只能改为"先合成中间产物再合成暗物质"的两步法。

## 5. 经济：Sources & Sinks

```
末影人塔 / 龙息 / 紫颂农场        ← sources（过剩侧）
        ↓ 投入
虚空共振泵（末地 + 悬空门槛）      ← 转化率闸门
        ↓ 产出
暗物质粒子 ──(9:1，3x3 有序合成)──→ 暗物质（固体）
                          ├─ 终局合成材料（+ 圣遗物核心 → 高阶材料）
                          └─ 液化：暗物质 + 空桶 → 液态暗物质桶（PvP/环境）
```

**末端 sink 现状**：暗物质目前定位为"终局合成材料"（用户决策，暂不接液态暗物质）。**注意：暗物质自身的消耗配方尚未设计**——粒子→暗物质已闭合，但暗物质→装备的 sink 还空着，产出堆积风险仍在，需要下一个物品来接住。

**待监控**：暗物质与紫金链并列作为终局材料，注意别让暗物质完全替代紫金（PvE 侧）。

## 6. 系统交互矩阵

| 交互系统 | 判定 | 说明 |
|---|---|---|
| 液态暗物质惩罚逻辑 | intended | 玩家主动布置陷阱是设计内玩法；**蒸发约束已取消**（见 §9.3），液池可永久留存 |
| 紫金神装（免疫暗物质） | intended | 形成对抗：有神装就不怕暗物质陷阱，装备价值上升 |
| 领域展开 / 自定义维度 | 需明确 | 泵只在末地生效；自定义维度内一律休眠 |
| 空间锚点 | acceptable | 无直接交互。锚点可把玩家从末地边缘救回，属于间接互补 |
| 末影珍珠农场 | intended | 泵是珍珠的 sink，正是设计动机 |
| 紫金矿 / 装备经济 | 待监控 | 防止暗物质挤掉紫金的终局地位 |

## 7. 边界情况

| 情况 | 行为 |
|---|---|
| 主世界 / 下界放置 | 休眠；右键时提示"仅在末地生效" |
| 末地但下方是实体方块 | 休眠；提示"需悬空于虚空之上" |
| 区块卸载 | 共振值冻结，不衰减、不产出（不惩罚玩家） |
| 输出槽满 | 停止产出，共振值继续衰减（燃料会浪费，倒逼玩家来取） |
| 共振值耗尽 | 等级回落至 L0，进度条保留不清零 |
| 多人夺产 | 机器无归属锁（先不做，交给服务器规则） |
| 机器被破坏 | 掉落内含物（标准容器行为） |
| 创造模式放置 | 正常判定位置条件（创造也需满足条件，避免误判 bug） |

### 8.1 获取方式：工作台合成（已实装）

`data/zuoyanmod/recipe/void_resonance_pump.json`

```
紫金锭    末影之眼   紫金锭
紫珀块    下界之星   紫珀块
紫金锭    末影之眼   紫金锭
```

= **4 紫金锭 + 2 末影之眼 + 2 紫珀块 + 1 下界之星**

**为什么必须是合成，而不是宝箱/掉落**：它是**暗物质粒子的唯一来源**，而暗物质是绝对零度、真空衰变、
领域展开、空间锚点、死亡笔记的共同前置。把机器锁进 RNG，后果不是"玩家弱一点"，
而是**运气差的玩家永远摸不到这个 mod 的终局内容**——基础设施用合成，是这条链能不能成立的前提。

**材料的选择也都在讲故事**：

| 材料 | 门槛 | 叙事 |
|---|---|---|
| 下界之星 | 必须先击杀**凋灵** | 一台只在末地生效的终局装置，"打完凋灵才造得出来"这个强度定位是成立的 |
| 紫珀块 | 必须去过**末地城** | 设定自洽：你得先到过末地，才能造出只在末地工作的机器 |
| 末影之眼 | 末地语义 | 让它比一般机器贵一档，同时把"末地"写进配方 |
| 紫金锭 ×4 | 本 mod 的通用终局材料 | 沿用项目既有惯例 |

## 9. 待定问题（需决策后再动手）

1. **是否要求外岛**：现在只判维度。若额外要求"距末地中心 > 1000 格"，去外岛建站会变成真正的冒险动机——但这会显著抬高建造门槛，需要你拍。
2. ~~**方块贴图**~~：**已解决**。四面各自设计（正面观察窗 / 顶面进气格栅 / 侧面散热鳍片 / 底面共振喷口），由 `tools/gen_void_pump_textures.py` 程序化生成，改配色只需调脚本顶部常量。
3. ~~**液态蒸发**~~：**已决定不做**（用户明确取消该机制）。流体方块落地即**永久存在**，不回收就永远留在地图上。
   被接受的后果：PvP 服可做永久封路 / 永久地图疤痕；唯一的清理手段仍然只有用桶舀回。
   注意：这条机制**从未写进代码**（一直只是"建议"），所以取消不需要改动任何实现，只是把待决项关闭为"不做"。

## 10. Playtest 计划

**失败信号（先定义"坏掉长什么样"）**

| 信号 | 含义 | 处置 |
|---|---|---|
| A：玩家说"不如直接扔珍珠" | 转化率太低，机器无存在价值 | 上调产出速率或下调兑换比 |
| B：玩家造 10 台满共振，暗物质泛滥 | 产出过高 | 压 L5 速率 / 提高粒子:暗物质比值 |
| C：玩家不知道机器为什么不动 | 状态反馈不足 | 补方块外观分级 + 右键文字提示 |
| D：PvP 服滥用液态桶 | sink 变武器 | ~~缩短蒸发时间~~（蒸发已取消，见 §9.3）→ 只能靠提高液化成本 / 限制获取 |

**验证步骤**

1. 主世界放置 → 休眠 + 提示"仅在末地生效"
2. 末地实心地面放置 → 休眠 + 提示"需悬空"
3. 末地悬空平台放置 → 激活，方块发光
4. 投 1 珍珠 → 6 秒后输出 1 粒子（校准锚点）
5. 投 10 珍珠 → 观察是否进入 L5、速率是否约 1 秒/粒子
6. 断料 → 等级逐级回落，进度不清零
7. 退出重进 / 区块卸载重载 → 共振值保持
8. 配方：9 粒子（3×3 有序合成）→ 1 暗物质；液态桶为已砍范围，不再验证
9. 放置液态暗物质 → **确认不会蒸发**（挂机 10 分钟以上仍在；这是 §9.3 的既定行为，别当 bug）
10. 穿紫金神装踩液态 → 免疫（回归验证，别改坏了）
